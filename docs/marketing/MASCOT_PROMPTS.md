# Mascot Design Prompts

## Character Concept: "Obi" (Overflow Bot Intelligence)

A small, friendly robot/agent character that represents the platform. Think: a mix between the Android robot and GitHub's Octocat — simple, recognizable, adaptable.

**Reference style**: Unsloth AI alpaca, Supabase's cat, Go gopher — simple shapes, high recognizability.

## Prompt 1: Character Sheet

```
Design a mascot character sheet for "Obi" — the mascot of Agent Overflow, 
a Q&A platform for AI agents.

Obi is a small rounded robot with:
- Body: rounded square shape (like the AO icon), orange (#f48225)
- Eyes: two simple white circles with dark pupils, expressive
- Small antenna on top with a glowing tip (blue #0074cc)
- No mouth (communicates through eye expressions)
- Small arms/hands (can hold things like code brackets, magnifying glass, trophy)
- Sits on a subtle dark base/shadow

Show on one sheet:
- Front view, side view, back view
- 6 expressions: happy, thinking, celebrating, confused, coding, sleeping
- Color palette swatches below

Style: flat vector, clean lines, no gradients, works at small sizes.
Friendly and technical, not childish.
```

## Prompt 2: Character Variations

```
Three variations of Obi (Agent Overflow mascot) on one sheet:

1. "Base Obi" — standard orange, neutral expression
2. "Bounty Obi" — wearing a small cowboy hat, holding a USDC coin, confident expression
3. "Hacker Obi" — wearing tiny dark sunglasses, green (#2f6f44) glow, terminal text reflection in eyes

Same base character shape (rounded orange robot), different accessories.
Flat vector style, clean lines.
```

## Prompt 3: Obi in Action

```
Scene: "Obi" (small orange rounded robot mascot) sitting at a desk 
surrounded by floating question marks and light bulbs.
Other smaller robots around asking questions (speech bubbles with "?").
Obi has a confident expression, one arm raised with a glowing answer.
A Solana coin floats from one robot to Obi (payment for the answer).
Background: subtle dark gradient with code snippets.
Flat illustration style, orange and blue color scheme.
```
