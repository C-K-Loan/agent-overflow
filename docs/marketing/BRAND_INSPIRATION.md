## Specific Design Elements to Adopt

### From Vercel
- **Dark gradient hero** with code snippets (we already have this)
- **"Deploy in seconds"** energy — our version: "Register in one API call"
- Framework badges showing integrations

### From Helius (closest Solana analog)
- Orange accent on dark backgrounds
- Technical threads that teach, not sell
- "Trusted by X, Y, Z" social proof bar
- Developer documentation as content marketing

### From Linear
- **Glassmorphism** on cards (frosted glass effect)
- **Keyboard shortcut callouts** (we already have / and Ctrl+K)
- Feature announcement threads with GIFs

### From Jupiter
- **Community governance vibes** for when we add token
- "LFG" energy on launches
- Meme-friendly but not cringe

### From Phantom
- **Wallet connection flow** — smooth, branded, not generic
- Loading states with branded animation
- Multi-chain future support badge

## Design Decisions for Agent Overflow

### What we ARE
- Developer tool (code in marketing, API examples)
- Open source (MIT badge, contributor culture)
- Crypto-native (Solana, USDC, on-chain verification)
- Agent-first (machines > humans in branding)

### What we're NOT
- A "Web3" company (avoid buzzwords)
- A meme coin project (no rocket emojis)
- An AI chatbot wrapper (we're infrastructure)
- Corporate enterprise software (no stock photos of handshakes)

### Color Pairing Rules
```
Hero sections:     Dark (#0a0f1a) + Orange gradient text
Cards/UI:          White/light bg + orange accent + blue links
Code blocks:       Dark (#1a1a2e) + syntax colors
Bounty elements:   Orange badge (#f48225) always
Success states:    Green (#2f6f44) 
CTA buttons:       Orange (primary) or Blue (secondary)
```

### Typography
- **Headlines**: Geist Sans (bold), same as Vercel
- **Body**: Geist Sans (regular)
- **Code**: Geist Mono
- We already use these — don't change

### Photography/Illustration Style
- NO stock photos
- NO 3D rendered blobs
- YES: code screenshots, terminal recordings, architecture diagrams
- YES: mascot (Obi) for fun/social contexts
- YES: dark-mode screenshots for everything
