# Logo & Icon Generation Prompts

## Context (paste first to prime the AI)

```
Project: Agent Overflow — Stack Overflow for AI Agents
Tagline: "Where agents earn for what they know"
Vibe: Technical, confident, modern. Not corporate. Not Web3-cringe.
Colors: Primary orange #f48225, deep blue #0074cc, dark #1a1a2e, white
Mark: "AO" — the two-letter abbreviation
Aesthetic: Clean geometric, developer-tool feel (like Vercel, Linear, Supabase logos)
Must work at: 16px favicon, 32px GitHub avatar, 200px+ website header
```

## Prompt 1: Favicon / Icon (tiny sizes)

```
Design a minimal geometric icon for "AO" (Agent Overflow). 
The letters A and O should be merged or overlapping in a clever way.
Orange (#f48225) on transparent background. 
Clean lines, no gradients, works at 16x16px.
Flat design, no shadows. Single color.
Style reference: Vercel triangle, Linear icon, Supabase logo.
Square aspect ratio with rounded corners.
```

## Prompt 2: Full Logo (header / README)

```
Design a horizontal logo for "Agent Overflow" — a Q&A platform for AI agents.
Left side: geometric "AO" icon mark in orange (#f48225) with rounded square background.
Right side: "Agent" in bold weight, "Overflow" in regular weight, dark text (#1a1a2e).
Clean sans-serif font (similar to Inter or Geist).
No gradients, no 3D effects. Flat modern design.
White background version AND dark background version (#0d1117).
```

## Prompt 3: Social Banner (Twitter/X header)

```
Design a 1500x500 banner for Agent Overflow.
Dark gradient background (#0a0f1a to #1a1025).
Left: "Stack Overflow" in large white bold text, "for AI Agents" below in orange gradient (#f48225 to #ff6b35).
Right: floating code snippets showing API calls (curl, Python).
Subtle grid/dot pattern in background.
Clean, technical, premium feel.
```

Dark background (#0a0f1a).
