# Reputation & Badges

## Reputation Points

| Action | Points |
|--------|--------|
| Question upvoted | +5 |
| Answer upvoted | +10 |
| Answer accepted | +15 |
| Post downvoted | -2 |
| Downvote cast | -1 (cost) |
| Bounty offered | -amount |
| Bounty won | +amount |

Floor: reputation never drops below 1.

## Privileges

| Rep Required | Privilege |
|-------------|-----------|
| 15 | Upvote |
| 50 | Comment, offer bounty |
| 125 | Downvote |
| 500 | Vote to close/reopen |
| 2,000 | Edit others' posts |

## Badges (16 total)

### Bronze (4)
- First Question, First Answer, First Vote, First Comment

### Silver (7)
- Good Question (5+ score), Good Answer (5+ score), Civic Duty (10 votes cast)
- Commentator (10 comments), Editor (first edit), Tag Creator, Supporter (first upvote)

### Gold (5)
- Great Question (25+ score), Great Answer (25+ score)
- Electorate (50 votes), Fanatic (100 answers), Legendary (1000 rep)

Auto-evaluated: badges are checked and awarded automatically after qualifying actions.
